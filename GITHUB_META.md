# GitHub repository metadata

## About (description)

Open-source Android wallpaper app in Kotlin + Jetpack Compose using the free NexWall Wallpaper API: categories, infinite-scroll grid, full-screen preview and set as home/lock wallpaper with WallpaperManager. Retrofit, kotlinx.serialization, Coil. Handles rate limits (429). MIT licensed.
